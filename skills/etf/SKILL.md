# ETF 数据查询

本技能自包含南方 ETFirst 的操作及字段参考、华宝 UDSP 的 Python 客户端与操作参考，不依赖另外安装的 etfirst 或 fsfund-etf-index 技能。运行仍需要 Python、ETFirst CLI 和对应服务凭据；初次配置或缺少运行环境时读[环境配置](references/setup.md)。不包含资讯技能、交易或组合管理；现有接口没有完整历史分红和原生股票反查 ETF 入口。华宝已实测支持主动基金的持仓单项查询，覆盖仍按具体基金和报告期核对。

## 选择数据源

用户指定来源时遵循其选择，仍须遵守所在项目的数据授权与来源限制。未指定时按下表选择，只读所选提供方的文档。

| 场景 | 优先 | 理由 |
|---|---|---|
| 盘中价格、涨跌幅、IOPV、溢折率 | 南方 | 提供带交易日与时刻的行情字段；原始数值缩放须先核实 |
| 预计算 PE/PB 历史分位、ROE 等展示指标 | 南方 | 详情中有相应预计算字段；具体含义以字段表为准 |
| 单只 ETF／联接基金快速概览、关联产品、简单分类浏览 | 南方 | 按产品组织的固定 CLI 与详情聚合 |
| 按管理人筛选、多代码比较或批量导出 | 华宝 | 接口可提供服务端过滤和逗号分隔多代码；先查当前 schema |
| 指定日期区间的日频行情、复权价格、净值、估值、规模或业绩序列 | 华宝 | 分项接口有日期条件及历史字段，部分接口支持大页 |
| Alpha／Beta／信息比率、PS／PCF 多口径、历史股息率 | 华宝 | 当前业绩和指数估值 schema 提供对应字段，范围与可用值需逐项检查 |
| 历史成分权重、持仓及资产配置变化 | 华宝 | 已实测日期范围与月权重；南方详情持仓可能仍返回最近披露期 |
| 全收益指数历史行情 | 华宝 | 先核实指数代码和历史覆盖；价格指数的股息率不能冒充全收益指数自身数据 |
| 主动基金的持仓等单项数据 | 华宝 | 已实测返回主动基金持仓；先检查 schema 并按基金验证，不承诺全面覆盖 |
| 只需某一类持仓、经理或资产配置，或定制聚合内容 | 华宝 | 可调用分项接口；360 聚合可按 schema 选择 `_members` |
| 指定南方／ETFirst／首趋E指或华宝／fsfund | 指定来源 | 认证与口径沿用该服务 |

以上是能力路由，不是准确性或速度排名；历史覆盖和最新日期均以实际返回为准。实现和实际调用证据见[能力核验](references/capabilities.md)。选择理由、边界及跨源核对见[来源比较](references/routing.md)，遇到两者都适用或需要切换时读取。

## 执行

1. 南方路径：读[ETFirst 指南](providers/etfirst/guide.md)，再按任务加载其字段参考。华宝路径：读[UDSP 指南](providers/fsfund/guide.md)，通过内置 CLI 的 `list-apis`、`schema` 确认接口与参数后调用。
2. 只请求必要产品、字段类别和日期范围。华宝单一指标使用分项接口，多类数据才聚合；南方按现有列表或详情命令调用；分页汇总须确认完整性。
3. 检查业务状态及聚合子结果。部分失败、空值、日期或单位不明要明确指出，不能当作零或默认当日。
4. 输出注明提供方、业务名称、单位，并在末尾“日期标注：”逐项标注。实时数据须有真实行情时间戳；日频、公告日、报告期分别解释。
5. 首选来源缺字段、不可用或时间不符时，按[来源比较](references/routing.md)判断另一家能否满足同一口径；不为普通查询默认双源取数，不将不同口径直接拼接。
