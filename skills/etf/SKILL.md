# ETF 数据查询

本技能自带三个数据源的操作参考和客户端：南方 ETFirst（字段参考，运行时是 ETFirst CLI）、华宝 UDSP（Python 客户端，接口由服务端元数据动态定义）、华泰柏瑞（Python 客户端与逐接口文档）。运行需要 Python 和各自的凭据；初次配置读[环境配置](references/setup.md)。不包含资讯、交易或组合管理；没有原生的股票反查 ETF 入口。华宝与华泰柏瑞都能查主动基金，覆盖按具体基金和报告期核对。

## 选择数据源

用户指定来源时遵循其选择，并遵守所在项目对数据来源的限制。未指定时按下表选择，只读所选来源的文档。

| 场景 | 来源 | 理由 |
|---|---|---|
| 盘中价格、涨跌幅、IOPV、溢折率 | 南方 | 带交易日与时刻的行情字段；原始数值缩放须先核实 |
| 预计算 PE/PB 历史分位、ROE 等展示指标 | 南方 | 详情里有预计算字段 |
| 单只 ETF／联接基金概览、关联产品、简单分类浏览 | 南方 | 按产品组织的固定命令与详情聚合 |
| 按管理人筛选、多代码比较、批量导出、全市场列表 | 华宝 | 服务端过滤、逗号分隔多代码、大页 |
| 指定区间的日行情、复权价格、净值、估值、规模或业绩序列 | 华宝 | 分项接口有日期条件；长区间不占华泰柏瑞的每日额度 |
| 全收益指数历史行情、指数历史成分权重、Alpha／Beta 等风险指标 | 华宝 | 已实测；历史权重直接给序列 |
| ETF 跟踪指数的盈利预测及其变化 | 华泰柏瑞 | 唯一来源 |
| 基金全部持股的申万一级行业分布、持仓加权估值 | 华泰柏瑞 | 唯一来源 |
| 基金经理的季报与年报观点原文、履历、标签、管理规模 | 华泰柏瑞 | 唯一来源或最完整 |
| 基金历史分红明细 | 华泰柏瑞 | 唯一来源 |
| 只有名称，需要精确的基金、指数、公司或经理代码 | 华泰柏瑞 | 精确映射，返回各种代码口径 |
| 用户指定南方／ETFirst、华宝／fsfund 或华泰柏瑞 | 指定来源 | 认证与口径沿用该服务 |

上表是能力路由，不是准确性或速度排名；历史覆盖和最新日期以实际返回为准。华泰柏瑞每天限 500 次调用，重叠的需求不用它。证据见[能力核验](references/capabilities.md)，选择理由、边界和跨源核对见[来源比较](references/routing.md)。

## 执行

1. 读所选来源的指南：[南方 ETFirst](providers/etfirst/guide.md)、[华宝 UDSP](providers/fsfund/guide.md)、[华泰柏瑞](providers/htbr/guide.md)。华宝通过 `list-apis`、`schema` 确认接口与参数；华泰柏瑞先查接口目录，再读对应接口文档。
2. 只请求必要的产品、字段和日期范围。分页汇总须确认完整性。
3. 检查业务状态和每个子结果。部分失败、空值、日期或单位不明要明确指出，不当作零或默认当日。
4. 输出注明来源、接口名称、单位，并在末尾“日期标注：”逐项标注。实时数据须有真实行情时间戳；日频、公告日、报告期分别说明。
5. 首选来源缺字段、不可用或时间不符时，按[来源比较](references/routing.md)判断另一来源能否满足同一口径；不为普通查询默认多源取数，不把不同口径直接拼接。
