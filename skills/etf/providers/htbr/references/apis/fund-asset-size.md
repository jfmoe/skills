# fund-asset-size

| 项 | 值 |
|---|---|
| `api_id` | `fund-asset-size` |
| 服务端登记名 | 资产规模 |
| 领域 | fund |
| 资料完整度 | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

查询基金**报告期规模与份额申赎序列**：期初/期末份额、申购/赎回份额、净申购、期末净资产。

适用：用户问「最近几个报告期规模多大」「份额是净申购还是净赎回」「资产规模变化」。

## 2. 不适用场景与易混接口

- 只要**最新规模单值**时用 `etf-capital-report` 的 `marketScale`，不必调本接口。
- 不提供净值、收益。

## 3. 请求参数

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `fundCode` | string | 是 | 6 位基金代码 |
| `beginDate` | string | 否 | 报告期起点（`yyyy-MM-dd`）；与 `endDate` 都不传 = 全历史 |
| `endDate` | string | 否 | 报告期终点（`yyyy-MM-dd`）；与 `beginDate` 都不传 = 全历史 |

> 入参面与上游 DS 报表一致：只有基金标识 + 报告期区间，**没有**取「最近 N 期」的参数——需要几期就用 `beginDate` 收窄。

## 4. 调用示例

```bash
pixi run etf-htbr invoke fund-asset-size '{"fundCode":"510300"}'
```

## 5. 返回数据路径与关键字段

读 `$.data.scaleHistory[]`，**报告期降序（最新在前）**，返回区间内**全部**报告期（不截断）：

| 字段 | 含义 |
|---|---|
| `startShares` / `endShares` | 期初 / 期末份额（**份**） |
| `applyingShares` / `redeemShares` | 申购 / 赎回份额（**份**） |
| `netApplyingShares` | 净申购 = 申购 − 赎回；**负值 = 净赎回** |
| `netAssetsValue` | 期末净资产（**元**） |

## 6. 数据口径

- 份额单位「份」，净资产单位「元」——规模展示换算为亿元并注明「元，÷1e8=亿」。
- 只出季报/半年报/年报等**定期报告期**（源表报告期类型 = 3），区间内按期全量返回，不按期数裁剪——答案里需要「最近 4 期」时自行取列表前 4 条。
- 净资产优先取季度财务指标表，缺失时回退年度表；两者都缺则该期为 `null`（不要按 0 处理）。
- 基金档案有效期已过的代码不出现在结果里（档案记录失效即整只基金无返回，不是该期缺数）。

## 7. 空数据与异常值语义

- HTTP 200 + 空数组 = 该区间无报告期数据，如实说明，不要补造。
- 代码不可解析 → 404 `FUND_NOT_FOUND`。

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），网关可达；调用间隔建议 ≥ 3 秒。
