# fund-rate

| 项 | 值 |
|---|---|
| `api_id` | `fund-rate` |
| 服务端登记名 | 基金费率 |
| 领域 | fund |
| 资料完整度 | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

查询基金**费率**：申购费、赎回费、管理费、托管费、销售服务费。

适用：用户问「管理费多少」「托管费多少」「申购赎回费率」「持有成本」等。

## 2. 不适用场景与易混接口

- 不提供收益、规模、净值 —— 分别走 `fund-stage-performance`、`fund-asset-size`、`fund-nav`。
- 不自行估算持有成本或给出投资建议：只展示原始费率说明与分档。

## 3. 请求参数

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `fundCode` | string | 是 | 6 位基金代码 |

## 4. 调用示例

```bash
pixi run etf-htbr invoke fund-rate '{"fundCode":"510300"}'
```

## 5. 返回数据路径与关键字段

读 `$.data.rates[]`，**每行 = 转型链内一个基金份额的一条有效费率**。

| 字段 | 含义 |
|---|---|
| `rateTypeDesc` | 费率类型，仅**申购 / 赎回 / 管理 / 托管 / 销售服务费**五类 |
| `rateDescription` | 原始费率说明 |
| `intervalDescription` | 分档说明（如按持有期分档的赎回费） |

## 6. 数据口径

- 同一基金可能有多行：转型链的多个份额段各占一行，需要按份额/时间段区分，不要只取第一行就下结论。
- 费率数值按服务端原始文案展示，**不做换算、不做年化、不合并档位**。

## 7. 空数据与异常值语义

- 无对应费率类型时该类型不出现在 `rates[]` 中，表示该基金无此项费用，如实说明。
- 代码不可解析 → 404 `FUND_NOT_FOUND`。

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），网关可达；调用间隔建议 ≥ 3 秒。
