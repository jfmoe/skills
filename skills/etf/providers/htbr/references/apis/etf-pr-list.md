# etf-pr-list

| 项 | 值 |
|---|---|
| `api_id` | `etf-pr-list` |
| 服务端登记名 | ETF申赎基本资料 |
| 领域 | etf |
| 资料完整度 | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

返回 ETF 的**申赎要素卡片**：申赎是否开放、最小申赎单位及其净值、单日申赎上限、现金差额、预估现金、现金替代比例上限、成分股数量。

适用：用户问「这只 ETF 能不能申购」「最小申赎单位多少份」「今天申赎开着吗」「成分股有几只」。

## 2. 不适用场景与易混接口

- **与 `etf-pr-components` 的区别**：那个给**成分股明细**；本接口只给成分股**记录数**。
- 与 `fund-daily-quote` 的区别：那个是行情；本接口是**申赎要素**。
- 只返回**最新清单日**，不支持指定历史交易日。

## 3. 请求参数

| 参数 | 类型 | 必填 | 规则 |
|---|---|---|---|
| `fundObject` | string[] | **是** | ETF 聚源**内码**列表；空 → 400；含非数字 → 400 |

## 4. 调用示例

```bash
pixi run etf-htbr invoke etf-pr-list '{"fundObject":["668474"]}'
```

## 5. 返回数据路径与关键字段

读 `$.data`（**每基金一行**，`records[]` 按 `fundCode` 升序、`tradingDay` 降序）：

| 字段 | 含义 |
|---|---|
| `fundObject` | 内码回显 |
| `fundCode` / `fundName` / `chiName` | 代码 / 简称 / 全称（无主表记录为 `null`） |
| `tradingDay` | 该基金**自身最新**清单交易日（`yyyy-MM-dd`） |
| `ifPurred` | 申赎允许情况，四组合文案见第 6 节 |
| `navPerLeastPRUnit` | 最小申赎单位资产净值（**元**），2 位小数 |
| `leastRedemptionUnit` | 最小申赎单位（**份**），整数 |
| `purchaseUL` | 单日申购上限（**份**），2 位小数 |
| `redemptionUL` | 单日赎回上限（**份**），2 位小数 |
| `cashBalance` | 现金差额（**元**），2 位小数 |
| `cashForecasted` | 预估现金部分（**元**），2 位小数 |
| `cashSubstituteProportion` | 现金替代比例上限（**%**），2 位小数 |
| `constituentCount` | 成分股**记录数**（无记录 = 0） |

## 6. 数据口径

- ⚠ **每只基金取自身最新清单日**，因此多只基金的 `tradingDay` **可以不同**；
  不要用其中一只的日期去解释另一只的数据。
- `ifPurred` 是申购、赎回两个开关的组合文案，四种取值：
  `允许申购|允许赎回`、`暂停申购|允许赎回`、`允许申购|暂停赎回`、`暂停申购|暂停赎回`。
  开关值非 1 一律按**暂停**处理。
- `cashSubstituteProportion` 已由小数换算为**百分数**（如源值 0.1 → `10.00`），直接加 `%`。
- `constituentCount` 与 `tradingDay` 严格对齐（同一清单日的成分股条数）。
- 金额类字段保留 2 位小数；与上游存在**末位舍入尾差**（上游向上舍入 vs 本服务四舍五入），对账时容忍末位差。

## 7. 空数据与异常值语义

| 现象 | 含义与处理 |
|---|---|
| 400 `PARAM_INVALID` | `fundObject` 为空，或含非数字内码 |
| 200 + 空列表 | 该内码无清单数据（**该基金不占行**），如实说明 |
| `fundCode` / `fundName` = `null` | 主表无该内码记录，但清单数据存在 |
| `constituentCount = 0` | 该清单日无成分股记录（不是缺失字段） |

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），网关可达；调用间隔建议 ≥ 3 秒。
- **必须先拿到 ETF 内码**；只有代码时先解析为 `InnerCode`。
- 仅支持最新清单日；历史快照当前不支持。
