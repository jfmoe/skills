# fund-monthly-return

| 项 | 值 |
|---|---|
| `api_id` | `fund-monthly-return` |
| 服务端登记名 | 月度周期收益 |
| 领域 | fund |
| 资料完整度 | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

查询基金的**逐自然月**收益明细。

适用：用户问「每个月收益怎么样」「月度收益明细」。

## 2. 不适用场景与易混接口

- 要**季度 / 年度**明细用 `fund-quarterly-return` / `fund-yearly-return`。
- 要**累计区间收益**（近三年累计）用 `fund-return-sum`；要**固定区间 + 同类排名**用 `fund-stage-performance`。

## 3. 请求参数

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `fundCode` | string | 是 | 6 位基金代码 |

## 4. 调用示例

```bash
pixi run etf-htbr invoke fund-monthly-return '{"fundCode":"510300"}'
```

## 5. 返回数据路径与关键字段

读 `$.data.months[]`：

| 字段 | 含义 |
|---|---|
| `tradingDay` | 该月周期截止交易日，**降序（最新在前）** |
| `monthlyReturn` | 该月收益率（**小数**，`0.0456` = +4.56%） |

## 6. 数据口径

- `monthlyReturn` 是**小数**不是百分数，展示须 ×100 加 `%`。
- 按**自然月**分组。
- **每只基金最早一期收益恒为 `null`**（无上期可比），属正常语义，展示为「—」。
- 上期净值为 0 时返回 `-1.0` —— 这是**除法口径的哨兵值，不是真实的 −100%**，不要照抄给用户。
- 历史收益仅客观陈述，不代表未来表现。

## 7. 空数据与异常值语义

- HTTP 200 + 空数组 = 无月度收益数据，如实说明。
- 首期 `null` 与哨兵值 `-1.0` 按上述口径处理，**不要**当作真实收益展示。

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），网关可达；调用间隔建议 ≥ 3 秒。
