# fund-basic-info

| 项        | 值                  |
| -------- | ------------------ |
| `api_id` | `fund-basic-info`  |
| 服务端登记名   | 基金基本信息             |
| 领域       | fund               |
| 资料完整度    | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

查询单只基金的**静态档案**：全称与简称、分类、运作方式、运行状态、业绩比较基准、成立日、管理人、托管人、规模。

适用：用户问「这只基金是什么/什么类型/什么时候成立/谁管的」，或需要在回答其它问题前先确认基金身份。按 SKILL.md「数据口径」总则，查基金基本信息优先实时接口（日行情、`etf-capital-report`），查询不到时再取本接口。

## 2. 不适用场景与易混接口

- **不要**用它取净值 —— 本接口响应**没有** `unitNav` / `navDate` 字段，净值走 `fund-nav`。
- **不要**用它取管理费/托管费 —— 走 `fund-rate`。
- 静态档案中的**最新**规模单值优先取 `etf-capital-report` 的 `marketScale`（实时口径）；要报告期序列（份额申赎历史）用 `fund-asset-size`。本接口 `fundSize` 为静态档案字段，实时接口查不到时作为兜底展示。
- 想按公司维度看多只基金，用 `fund-company-funds`。

## 3. 请求参数

| 参数         | 类型     | 必填 | 约束                                                      |
| ---------- | ------ | -- | ------------------------------------------------------- |
| `fundCode` | string | 是  | 6 位基金代码（如 `510300`）。传入不可解析的代码时接口返回 404 `FUND_NOT_FOUND` |

## 4. 调用示例

```bash
pixi run etf-htbr invoke fund-basic-info '{"fundCode":"510300"}'
```

## 5. 返回数据路径与关键字段

读 `$.data`，共 22 个字段，已确认的关键字段：

| 字段                         | 含义                     |
| -------------------------- | ---------------------- |
| `secuCode` / `secuAbbr`    | 证券代码 / **简称（对外展示优先用）** |
| `chiName`                  | 基金全称                   |
| `thirdAssetCatName`        | 类型（聚源三级分类）             |
| `dataValue`                | 类型（证监会分类）              |
| `runType`                  | 运作方式                   |
| `runStatus` / `fundStatus` | 运行状态 / 申赎状态            |
| `performanceBenchMark`     | 业绩比较基准                 |
| `establishmentDate`        | 成立日                    |
| `investAdvisorName`        | 管理人                    |
| `trusteeName`              | 托管人                    |
| `fundSize`                 | 规模（元）                  |

## 6. 数据口径

- `fundSize` 单位是**元**，展示层换算为亿元（`÷1e8`）。
- 其余字段按服务端原值透传，不做二次计算。

## 7. 空数据与异常值语义

- 代码不可解析 → HTTP 404 `FUND_NOT_FOUND`，如实告知该代码无对应基金，**不要**用近似代码或其它接口的数字替代。
- 响应中个别字段为 `null` 时，表示该基金该项无数据，展示为「—」，**不要**当成 0，也不要照抄 `null` 字样（会被最终校验拦截）。

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），且网关可达（见 `SKILL.md`「凭证缺失或失效」）。
- 同一会话内多次调用会复用短期 Token；调用间隔建议 ≥ 3 秒。

## 9. 相关工作流

无。本接口是多数其它接口的身份确认前置步骤。
