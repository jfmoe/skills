# fund-dividend-history

| 项 | 值 |
|---|---|
| `api_id` | `fund-dividend-history` |
| 服务端登记名 | 基金分红历史 |
| 领域 | fund |
| 资料完整度 | 完整（请求 + 响应 + 口径均有） |

## 1. 功能与适用场景

查询基金**历史分红记录**：每 10 份派现金额、关键日期、累计分红次数。

适用：用户问「这只基金分红过几次」「每次分多少」「什么时候登记的」。

## 2. 不适用场景与易混接口

- 只提供**已发生**的历史分红事实，**不代表**未来收益或后续分红预期。
- 不提供净值与收益率 —— 走 `fund-nav`、`fund-stage-performance`。

## 3. 请求参数

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `fundCode` | string | 是 | 6 位基金代码 |

## 4. 调用示例

```bash
pixi run etf-htbr invoke fund-dividend-history '{"fundCode":"510300"}'
```

## 5. 返回数据路径与关键字段

读 `$.data.dividends[]`：

| 字段 | 含义 |
|---|---|
| `divPer10UnitsPreTax` | 每 10 份派现（税前） |
| `divPer10UnitsAfterTax` | 每 10 份派现（税后） |
| 登记日 / 除息日 / 发放日 / 再投资日 | 各分红关键日期 |
| 累计分红次数 | 该基金历史分红总次数 |

## 6. 数据口径

- 派现口径是**每 10 份基金份额**的金额，不是每份，回答时须写清单位。
- 税费口径分列税前/税后两值，不要混用。

## 7. 空数据与异常值语义

- HTTP 200 + 空数组 = 该基金**无历史分红记录**，这是正常语义不是故障，如实告知。
- 代码不可解析 → 404 `FUND_NOT_FOUND`。

## 8. 前置条件与调用限制

- 需已配置 API Key（`config.py status` 为 configured），网关可达；调用间隔建议 ≥ 3 秒。
