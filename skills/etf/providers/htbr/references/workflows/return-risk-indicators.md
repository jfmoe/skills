# Workflow：收益风险 7 指标共享口径

> 适用：用户问基金的收益/风险指标（累计收益、最大回撤、夏普、卡玛、信息比率、年化收益、年化风险）。
>
> 这 7 个接口**共享同一套入参口径**，规则集中在本文件；各接口自身的字段与单位见
> `references/apis/<api_id>.md`。**不要**在本文件复制各接口的参数定义。

## 涉及接口

| api_id | 指标 | `dataValue` 单位 |
|---|---|---|
| `fund-return-sum` | 区间累计收益 | **%** |
| `fund-max-dd` | 最大回撤 | **%**（实测为正数） |
| `fund-sharpe` | 夏普比率 | **无量纲** |
| `fund-calmar` | 卡玛比率 | **无量纲** |
| `fund-info-ratio` | 信息比率 | **无量纲** |
| `fund-annual-return` | 年化收益 | **%**（仅 6 个年化周期） |
| `fund-annual-risk` | 年化风险（波动率） | **%** |

## 共享入参口径

### 1. `fundCode` 使用目标指标的 GilCode 口径

- 入参是目标指标口径的 **GilCode**。用户只给名称、净码或代码口径不符时，先按 `fund-code-resolution.md` 精确映射，唯一候选取 `gilCode`，不得自行添加或改写后缀。
- 既有实测 `.OF` 示例含场内 ETF，但不能据此推断所有代码的后缀。用户直接给出的 GilCode 已符合目标口径时可直接使用。
- ⚠ `.SH` / `.SZ` 曾观察到静默返回 `recordCount=0`。先核对原始输入和精确映射，不得把空结果当成改后缀的理由。

### 2. `beginDate` / `endDate` 的语义（最容易误用）

- 格式 `yyyy-MM-dd`，**实务上必须传**。
- ⚠ 它们**只过滤指标的计算日 `endDate`**（返回行的 `endDate` 落在该区间内），
  **不是指标的统计窗口**。
- 「近一年 / 近三年 / 近五年」由返回行的 **`indexCycle`（12 / 36 / 60）** 决定 ——
  传不传日期、传什么区间，这些周期数都不会变。

### 3. 必须传「近年窄区间」

- 不传日期、或区间过宽时，接口会**长时间不返回**（实测 > 240s 超时）；
  改用近一年的窄区间后降到 **~13s**。
- **默认按「近一年到今天」传**，除非用户明确要别的时间段。
- 传入与计算日**无交集**的区间（如 2020 年）会返回 `recordCount=0`，这是**正常语义不是故障**。

### 4. `indexCycle` 周期全集

- 实测全集：`3 / 6 / 12 / 24 / 36 / 60 / 120`（三/六/十二/二十四/三十六/六十/一百二十个月）
  `+ 998`（今年以来）`+ 999`（成立以来）。
- 一行一个周期。**近一年 = 12、近三年 = 36、近五年 = 60**。
- `fund-annual-return` 只覆盖 **6 个年化周期**，不含「今年来 / 成立来」。

### 5. 排名字段的例外

- `dataValueRanking`（「名次/总数」文本）与 `rankingRatio`（分位 %，**越低越靠前**）
  **只有 `fund-return-sum` 与 `fund-max-dd` 返回**，且**部分周期为 `null`**。
- 其余 5 个接口不返回这两个字段，不要凭空补排名。

### 6. 时效与表述

- `endDate` 是**指标计算日**，可能落后最新净值日数天，引用时按其注明「截至」。
- 所有指标**仅客观陈述**，不构成投资建议。

## 特殊编排：`fund-max-dd` 不给回撤起止日

`fund-max-dd` **只给回撤幅度**。用户问「回撤最大的那段时间是什么时候」时，按下列**前缀峰值法**自算：

1. 用 `fund-nav-trend` 取**同期**的复权收益链。
2. `level = 1 + value`
   —— `value` 是该接口给的**区间累计收益率**（复权口径）。⚠ **`level` 可能跨 0，不能当净值用。**
3. 逐日算 `dd = level / max(level…当日) − 1`。
4. 取 `min(dd)` 所在日为**谷底日**，其**前缀峰值**所在日为**峰值日**。

**口径校验记录**：2026-09-23 用此法在 `510300` 上复算近 1 / 3 / 5 年，得
`11.17% / 15.32% / 35.16%`，与 `fund-max-dd` 返回的同周期值**逐一对齐**，故此口径可信。
