# ETFirst

使用已安装的 ETFirst CLI 查询指数及指数型基金。适用于 ETFirst 0.4.2；不支持交易、主动基金详情、组合管理或实时推送。

## 执行入口

在使用 Pixi 管理 ETFirst 的项目中，将参考文档里的 `etfirst` 替换为 `pixi run etfirst`；其他环境使用已安装的 `etfirst`。参数不确定时查看对应子命令的 `--help`，无子命令会进入交互模式。

详情的 `all` 在 CLI 0.4.2 中只发一次服务端聚合 POST，不能按子结果数量计算客户端请求数。起止日期由服务端处理，返回后逐个序列核对实际范围；最新行情不随历史查询区间回放。

## 按任务读取

只读取当前任务对应的参考文件；不要一次加载全部字段表。

| 任务 | 调用前读取 | 命令 |
|---|---|---|
| 分类、产品列表、筛选、排序或分页汇总 | [列表查询](references/list.md) | `index-base clas` / `index-base list-etf` |
| 指数估值、行情、成分、资金流或历史序列 | [指数详情](references/index.md) | `index-detail all --index-code CODE` |
| ETF 行情、持仓、经理、收益或联接关系 | [ETF 详情](references/etf.md) | `etf-detail all --product-code CODE` |
| 场外联接基金规模、持仓、份额或收益 | [场外详情](references/otc.md) | `otc-detail all --product-code CODE` |
| 登录、退出、配置或认证错误 | [认证](references/auth.md) | `auth` / `config` |

需要展示或计算数值指标时，另读 [日期、单位与展示](references/presentation.md)。只有名称、代码或分类的查询无需加载该文件。

## 完成查询

1. 确定产品类型与代码，按上表选择命令并使用 `--json`。仅查询用户需要的范围；需要多类详情时使用聚合命令。持续轮询建议间隔至少 5 秒。
2. 检查退出码及业务状态。普通响应的 `code` 为 `00000`、`0000` 或 `000000` 表示成功；聚合响应需逐项检查 `results` 和 `_errors`；预期子项缺失也算数据缺口，不能仅凭 `_errors` 为空认定成功。保留可用结果并说明缺失项。
3. 全量筛选或汇总须按列表参考完成分页；展示实时行情须按日期参考取得真实时间戳。不能用列表页的收益日期代替行情时间。
4. 用业务名称和对应单位呈现结果，数值指标在回复末尾逐项标注日期。缺失值、日期或失败子接口不能当作零值或当日数据。
