# 适配器

## 意图

把一个现有对象的接口转换成调用方期望的接口，使两个原本不是为彼此设计的东西能够在任何一方都不修改的情况下协作。

## 它解决的问题

你依赖一个类——第三方 SDK、遗留模块、外部服务客户端、原始数据库行——它的接口与代码所需的不匹配。你可以改写所有调用方去说那个外来接口，但那会把依赖散播得到处都是，并把你的领域耦合到一个你无法控制的形状上。适配器把不匹配关进一个包装对象里。调用方看到你拥有的稳定接口；适配器负责翻译。

这是依赖倒置原则的运行时表达：高层代码依赖它自己定义的抽象，适配器让一个具体的外部事物满足它。

## 结构与参与者

- **目标（Target）**：客户端想用的接口（在 Python 中通常是 `Protocol` 或非正式的鸭子类型契约）。
- **被适配者（Adaptee）**：接口不兼容的现有对象。
- **适配器（Adapter）**：实现 Target 并转发给 Adaptee 的对象，跨边界翻译数据和错误。
- **客户端**：使用 Target、从不见到 Adaptee 的代码。

经典的区分是**对象适配器**与**类适配器**。对象适配器把被适配者*持有*为属性并委托给它；类适配器同时*继承*目标和被适配者。对象适配器几乎在所有地方都更受青睐，因为它是组合而非纠缠继承、能适配不是你创建的实例、并且能适配多个被适配者。类适配器需要多重继承，并在定义时就绑定到被适配者的类。在 Python 中优先用对象适配器；只有当你确实需要成为被适配者的子类型时才用继承。

## 何时使用

- 隔离第三方 SDK、遗留 API 或外部服务，使其余代码依赖你的接口而非他们的。
- 把几个不同的后端（支付渠道、存储驱动、通知通道）归一化到一个契约之后。
- 在系统边界转换数据表示：线路格式、ORM 行、协议消息转成领域类型。

## 何时不使用

- 接口已经匹配，或鸭子类型让对象可以原样使用。一个只改方法名的包装器是纯粹的开销。
- 你真正想要的是一个围绕你的需求设计的*新*接口，而不是对现有接口的翻译；那就直接写那个接口，而不是给旧的梳妆打扮。
- 被适配者是你的、你可以改它。修源头，而不是永久地包着它。

## 失败模式

- **泄漏或透传的适配器**：一对一转发调用、不做任何翻译，平白增加一跳和一个要翻阅的文件。
- **过度隐藏**：吞掉被适配者的错误、重试、超时和性能特征，使调用方无法正确反应。适配器应翻译失败语义，而不是抹掉它们。把 `StripeError` 映射为领域里的 `PaymentDeclined`；不要返回 `None`。
- **臃肿的适配器**：堆积业务逻辑。适配器做翻译；一旦它开始做决策，它就变成了别的东西，应该相应地命名。

## Python 示例

持有被适配者并在边界处翻译：

```python
class PaymentGateway(Protocol):
    async def charge(self, order: Order) -> PaymentResult: ...


class StripeGateway:
    def __init__(self, client: StripeClient) -> None:
        self._client = client

    async def charge(self, order: Order) -> PaymentResult:
        try:
            response = await self._client.create_charge(order.total_cents)
        except StripeError as exc:
            raise PaymentDeclined(order.id) from exc
        return PaymentResult.from_stripe(response)
```

适配器不一定是类。一个把外来 dict 映射为领域 `dataclass` 的薄函数就是适配器。鸭子类型还消除了许多适配器的必要：如果一个对象已经有了你调用的方法，你就不需要仅为满足名义接口而加包装器。

## 与其他模式的关系

适配器改变接口而不改变行为；[decorator.md](./decorator.md) 保持接口并增加行为；[facade.md](./facade.md) 在许多对象之上定义一个全新的、更简单的接口，而不是翻译一个。适配器和 [strategy.md](./strategy.md) 常一起出现：适配器所满足的 `Protocol` 往往就是策略插入的同一个抽象。对于类型驱动的值转换，`functools.singledispatch` 可以充当轻量的适配器分发。
