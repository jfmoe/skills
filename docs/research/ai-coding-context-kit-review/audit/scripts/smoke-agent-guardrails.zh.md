# Agent 门禁 smoke 测试说明

[English implementation](smoke-agent-guardrails.mjs)

该脚本只测试候选门禁代码，不对提示词或文本文档编写单元测试。它在系统临时目录中创建相互隔离的 Git 仓库，完成后删除这些临时仓库。

覆盖 5 个场景：

1. 暂存区中的规范源、投影、产物和伴随文件同步变化时通过。
2. 伴随文件从暂存快照删除、但仍作为未跟踪工作区文件存在时失败，证明工作区文件不能掩盖暂存删除。
3. 受保护路径被重命名时失败，证明旧路径也接受检查。
4. 只修改生成投影、不修改规范源时失败。
5. 使用固定 base 到 HEAD 的完整结果快照时通过。

脚本还检查失败消息属于目标规则，避免仅凭非零退出码误判测试成功。
